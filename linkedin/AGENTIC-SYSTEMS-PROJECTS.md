## Project 4: Agentic Systems Evaluation Lab

Project URL: https://agentic-systems-evaluation-lab.vercel.app

Repository: https://github.com/syedahmad0786/agentic-systems-evaluation-lab

Description:

Built a live black-box evaluator for deployed agentic systems. It runs seven weighted checks across availability, typed contracts, evidence, approval gates, live-provider boundaries, idempotency, trace depth, and latency. ## Project 5: Content Performance Forecaster

Project URL: https://content-performance-forecaster.vercel.app

Repository: https://github.com/syedahmad0786/content-performance-forecaster

Description:

Built a pre-publish content decision system using 500 licensed public Facebook post records. A deterministic 400-row training and 100-row holdout split produces versioned ridge-regression artifacts, interval coverage, forecast ranges, cohort fallback, confidence, and counterfactual input sensitivity. The interface states that results are historical baselines, not promised views, and does not pretend the dataset supports Florida-level predictions.

Technical proof: Python, FastAPI, Pydantic, versioned model artifacts, holdout evaluation, prediction intervals, input sensitivity, data-contract checks, Pytest, GitHub Actions, Vercel, Postman, structured logs, and trace IDs.

Skills: Python, Machine Learning, Model Evaluation, Forecasting, FastAPI, Pydantic, REST APIs, Data Validation, Observability, Postman, GitHub Actions
