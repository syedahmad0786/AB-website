A 7-day ad report should end in the next creative brief.

The workflow connects the reporting record to creative analysis and a review-to-copywriting request, so an operator can turn performance context into the next production decision.

Report → review → copy; with separate reporting and creative-strategy source workflows. Original workflow structure and historical forms, not a measured ROAS improvement.

Collect a report with its period intact

The weekly Facebook report source and the creative-strategy source are shown in native local n8n views. A retained historical report covers February 27 to March 2, 2025; its values are recorded document content, not current performance.

Give the reviewer the analysis context

The report belongs with the available observations and the next question for the creative team. A summary document alone is not an implementation outcome, so the backend structure and review handoff are visible alongside it.

Create a reviewable production request

The historical interface includes the ready-to-copywriter decision and copywriting instructions. This makes the next handoff inspectable instead of implying that an AI report automatically became published ads.

Quantify only the available basis

The seven-day reporting window and separate source workflows are concrete scope. No advertising lift or hours saved are added without a baseline and a comparable observed period.
